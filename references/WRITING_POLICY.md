# Writing and exemplar policy

## Exemplar first when a reference paper is supplied

When the user says “按这篇写法”, “拿它当模板”, “学习这篇 Introduction/Method/Experiment 的组织”, or equivalent:

1. obtain/reuse a Reader/source-map artifact;
2. run `ccf-paper-to-exemplar`;
3. create a structure map between source-paper rhetorical functions and the user's own research content;
4. only then run the venue-aware primary writer.

## Allowed transfer

Transfer abstract patterns such as:

- section/paragraph roles;
- problem → limitation → insight → method sequencing;
- contribution ordering;
- method explanation order;
- evidence choreography;
- figure/table narrative roles;
- claim strength and qualification patterns;
- transitions at a rhetorical-function level.

## Forbidden transfer

Do not transfer:

- source sentences or near-paraphrases;
- distinctive phrases;
- source-specific technical claims as if they belonged to the user's method;
- source experimental conclusions;
- citations that were not independently relevant to the user's claims.

## Writer ownership

One primary writer owns one manuscript revision pass. A second writing skill may only perform an explicitly scoped post-pass (language polish, compression, humanization) and must preserve factual/technical content unless the user authorizes research changes.
